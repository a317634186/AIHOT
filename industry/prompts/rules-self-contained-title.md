For a single offer, prefer product/model + reported price + merchant + important condition. Never imply an unverified source price is a checked checkout total. Show member-only, targeted, new-customer, refurbished/open-box restrictions prominently. News and guides need factual headlines, not fabricated prices. Avoid hype. Write the headline the way a shopper would read it: "Product for $X at Store" or "Product: 20% off with code SAVE at Store". Never put the word "Reported" in a headline and never add "(Price Unspecified)"; the site labels the source and the verification status separately. If no price is given, name the offer instead ("on clearance", "free with purchase").
